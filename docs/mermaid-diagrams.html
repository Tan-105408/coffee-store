4. 6. SEQUENCE DIAGRAM — THANH TOÁN PAYOS

sequenceDiagram
    autonumber
    participant C as Client Browser
    participant S as Express Server
    participant P as PayOS API
    participant E as Gmail SMTP
    participant D as SQL Server

    C->>S: POST /checkout {paymentMethod: payos, voucher}
    S->>S: Validate voucher + tính tổng
    S->>D: Create Order (status=pending, paymentStatus=pending)
    D-->>S: order {id, totalAmount}
    S->>P: POST /v2/payment-requests {orderCode, amount, ...}
    P-->>S: {checkoutUrl}
    S-->>C: Redirect đến checkoutUrl

    rect rgb(245, 245, 245)
        note over P: User thanh toán trên PayOS
        P->>S: POST /webhook {orderCode, status: PAID}
        S->>S: Verify signature HMAC-SHA256
        S->>D: Update Order → completed, delete cart
        S->>E: Gửi email xác nhận
        S->>S: autoAssignVoucher() nếu đủ milestone
    end

    C->>S: GET /payment/return
    S-->>C: Render checkout_success

5. 7. SEQUENCE DIAGRAM — TỰ ĐỘNG GÁN VOUCHER

sequenceDiagram
    autonumber
    participant O as Order completed
    participant VS as VoucherService
    participant DB as SQL Server

    O->>VS: checkAutoAssignment(order)
    VS->>DB: Lấy tất cả VoucherRule (isActive)
    DB-->>VS: [{rule}]

    loop Mỗi rule
        VS->>DB: [trigger=totalSpend] aggregate tổng chi tiêu user
        VS->>DB: [trigger=orderCount] count đơn user
        DB-->>VS: giá trị milestone
        alt Đủ threshold && chưa có
            VS->>DB: Upsert UserVoucher
            DB-->>VS: OK
        end
    end

9. 11. SEQUENCE DIAGRAM — ĐĂNG NHẬP

sequenceDiagram
    autonumber
    participant C as Client Browser
    participant S as Express Server
    participant D as SQL Server

    C->>S: POST /auth/login {username, password}
    S->>D: findFirst(user by username)
    D-->>S: {user data}
    S->>S: bcrypt.compare(password)
    alt Sai mật khẩu
        S-->>C: Lỗi "Sai tên đăng nhập hoặc mật khẩu"
    else Đúng
        S->>S: req.session.userId = user.id
        S-->>C: Redirect "/"
    end
